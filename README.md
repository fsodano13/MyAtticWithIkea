# MyAtticWithIkea

Configuratore 3D per una parete attrezzata IKEA PLATSA in mansarda (nicchia 235 × 246 cm).

- Visualizzazione 3D interattiva (three.js) della stanza con falda, travi e soffitto
- Configurazione per colonna + 3 moduli PLATSA: ante, cassetti, vani a giorno
- Controllo automatico delle collisioni: ante che sbattono contro la falda/travi, cassetti aperti, altezza totale
- Lista componenti generata in automatico
- La configurazione viene salvata nel browser (localStorage)

## Come si apre

Pagina online: https://fsodano13.github.io/MyAtticWithIkea/

In locale basta aprire `index.html` in un browser.
